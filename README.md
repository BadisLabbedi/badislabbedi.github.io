# Badis Labbedi — Portfolio

Static academic portfolio for https://badislabbedi.github.io/.

## Editing and preview

Edit `index.html` for content, `styles.css` for presentation, and `app.js` for navigation and the portrait theme toggle. Open `index.html` locally; no build or installation is needed.

## GitHub Pages

Publish from the `main` branch, `/(root)`, in Settings → Pages. This repository must be public on the current GitHub plan. After Pages is enabled, changes pushed to `main` are published automatically.

## Assets

Fonts and font licenses are in `assets/`. Portrait drawing by K. Rey, supplied by the site owner.
