# Badis Labbedi — Portfolio

A minimal academic portfolio with locally hosted fonts, a portrait, education, current project titles, a talk outline, and contact links.

## Edit

- `index.html`: biography, education, research titles, talk, and links.
- `styles.css`: layout, portrait sizing, typography, and responsive styles.
- `app.js`: mobile navigation and active section indicator.
- `assets/`: portrait, favicon, fonts, and font licenses.

This is a complete static website. No build step, package installation, or server-side service is required. Serve this directory with any static web server. The files are also suitable for GitHub Pages.

The EB Garamond and Courier Prime font licenses are included alongside the font files. Research entries describe projects and working notes; inclusion does not imply publication.
